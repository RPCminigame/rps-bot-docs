# Privacy Policy

This bot ("RPC minigame") is a Rock-Paper-Scissors mini-game for Discord.

## What data is stored

- Discord user ID
- Discord server ID
- Display name
- Game statistics (wins, losses, draws, streaks)
- Virtual coin balance
- Timestamp of the last daily bonus

## Why it is stored

Only to make the game work: saving your score, showing leaderboards,
managing coins and daily bonuses.

## Where it is stored

Locally in JSON files on the Bot owner's machine. No data is sent
to any third party.

## Your rights

You can request a copy or deletion of your data at any time by
contacting the Bot owner on Discord.

## Contact

For any questions, contact the Bot owner on Discord.
